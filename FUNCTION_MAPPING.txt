====================================================

The V5 Action List uses the EXISTING AutomationBuilderService and AutomationStepType
definitions. It does not create decorative buttons that bypass the real job system.

Farm-Reel-style V5 workflow
---------------------------
1. Select one or more accounts.
2. Click Action List...
3. Check authorized actions.
4. Configure the selected action on the right.
5. Reorder the selected action list.
6. Configure retry, timeout, delay metadata, approval, and continue-on-error.
7. Dry Run.
8. Start.
9. Open Job Queue to monitor actual jobs.

Verification flow
-----------------
If an account needs a platform verification/challenge, SP-Farms should surface
"User action required", allow the operator to finish the verification, then resume.
The V5 patch does not add CAPTCHA/checkpoint bypass.

Not mapped from the demo
------------------------
The following demo ideas are intentionally not turned into automation steps:
- CAPTCHA/checkpoint solving or security bypass
- bulk friend adding / friend-confirm farming
- automated watch/live/newsfeed activity farming
- automated like/follow/reaction farming
- unsolicited bulk messaging
- fake fingerprint/device identity evasion for Facebook

This keeps the existing SP-Farms safe-device and authorized-asset model intact.
