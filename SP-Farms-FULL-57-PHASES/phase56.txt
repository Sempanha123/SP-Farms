======================================================================
2. THEME DIRECTION
======================================================================

Default theme should follow the supplied dark reference.

Base:
- near-black / charcoal application background
- slightly lighter panel surfaces
- thin muted borders
- high-contrast white/off-white text
- yellow/gold primary action accent
- green success/online accent
- blue informational accent
- red destructive/error accent
- gray inactive/offline states

Do not use:
- neon glow
- oversized gradients
- glassmorphism
- huge rounded cards
- large empty whitespace
- overly soft mobile-style UI

The look should be:
- compact
- sharp
- professional
- cute through icons, spacing, and micro-details
- desktop-first
- information-dense

======================================================================
3. PRIMARY COLOR TOKENS

Create semantic tokens, not hardcoded widget-by-widget colors.

Suggested direction:

- `bg_app`: very dark charcoal
- `bg_surface`: dark charcoal panel

- `border_default`: muted gray/yellow-tinted neutral

- `text_secondary`: muted light gray
- `text_disabled`: muted gray

- yellow/gold action accent

- green

Info:
- blue

- amber/orange

- dark yellow/olive tint, not bright neon

Keep color usage restrained.

======================================================================
11. CUTE WITHOUT LOSING DENSITY
======================================================================

"Cute" should come from:
- friendly rounded icons
- small status dots
- subtle pill shapes
- consistent small radii
- polished spacing
- tiny micro-animations
- gentle hover transitions
- clean typography
- friendly empty states

Do NOT make it:
- childish
- pastel-heavy
- bubbly/mobile-like
- oversized

The supplied reference is the primary style direction.

======================================================================
12. LIGHT THEME
======================================================================

Keep an optional light theme, but dark theme is the reference/default.

Light theme should preserve:
- same layout
- same density
- same yellow accent
- same hierarchy

Do not redesign layout separately for light mode.

======================================================================
13. RESPONSIVENESS
======================================================================

Support:
- 1366x768
- 1600x900
- 1920x1080
- larger displays

At smaller sizes:
- inspector/modal content may scroll internally
- keep top nav compact
- never hide critical actions without an overflow alternative

Do not break the reference-like layout at 1366x768.

======================================================================
14. NON-BLOCKING VISUAL STATES
======================================================================

During long tasks:
- keep modal interactive
- show inline progress
- show status text
- show progress bar only where useful
- update task state through signals/events

Example:
`Connecting VPN...`
`ADB Ready`
`Restoring Workspace...`
`Opening App...`
`Ready`

Do not freeze the UI.

======================================================================
15. ICONOGRAPHY
======================================================================

Use one coherent icon family.

Icons should be:
- simple
- compact
- legible at 14–18 px
- mostly outline/duotone
- consistent stroke weight

Avoid mixing multiple unrelated icon packs.

======================================================================
16. TYPOGRAPHY
======================================================================

Use a clean UI font available/licensed for the application.

Scale:
- app title: compact
- section title: medium-bold
- table text: compact
- secondary metadata: smaller muted text

Avoid huge headings.

Keep baseline alignment exact.

======================================================================
17. SPACING SYSTEM
======================================================================

Use a restrained spacing scale, for example:
- 4
- 6
- 8
- 12
- 16
- 20

Do not use large 32/48 px gaps in normal management screens.

The reference is dense and should stay dense.

======================================================================
18. BORDER / RADIUS SYSTEM
======================================================================

Suggested:
- 1 px borders
- 4–8 px radius for most controls
- 8–10 px for larger panels/modal

Do not make everything 16–24 px rounded.

Modal yellow outline should be thin, not glowing.

======================================================================
19. HOVER / ACTIVE STATES
======================================================================

Buttons:
- subtle lighter/darker hover
- no strong glow

Active:
- clear yellow/gold fill or border

Table rows:
- subtle hover tint
- selected state distinct but restrained

Focus:
- accessible visible outline
