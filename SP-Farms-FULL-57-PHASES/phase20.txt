======================================================================
PHASE 20 — ACCOUNT DEVICE PROFILES AND RESTORE WORKSPACE
======================================================================

Give each account a remembered legitimate device environment.

IMPLEMENT:
- DeviceProfile:
  UUID, friendly name, provider, emulator instance, ADB serial, actual Android version/model, resolution, DPI, language, locale, timezone, keyboard config, app versions, preferred Facebook app, network profile ref, heartbeat.
- AccountDeviceBinding:
  account id, device profile id, preferred app, status, created/last-used time.
- "Restore Workspace" action:
  1. resolve binding
  2. start assigned emulator if needed
  3. wait for ADB
  4. validate Facebook/Facebook Lite/browser availability
  5. apply harmless saved preferences where supported
  6. launch selected app
  7. show current auth/security state
  8. request supported re-auth if needed
  9. update last-used/heartbeat

DO NOT:
- generate fake device identity
- inject auth state to bypass security

TEST:
- restore with offline device
- restore with missing app
- restore with started/stopped emulator
- binding persistence

DONE WHEN:
- one account can reliably return to its assigned legitimate device workspace.
