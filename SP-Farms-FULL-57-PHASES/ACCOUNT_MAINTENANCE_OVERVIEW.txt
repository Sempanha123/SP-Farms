Typical secure pipeline:
Resolve Account
→ Resolve Device only if required
→ Apply required Network Profile
→ Restore Workspace if required
→ Run maintenance action
→ Verify result
→ Update secure vault refs
→ Backup metadata
→ Release device
→ Next account

No checkpoint bypass, recovery-code interception, session injection, or plaintext secret storage.
