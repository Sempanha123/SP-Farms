RESTORE PIPELINE

Select Account or Page
    ↓
SP-Farms resolves Account
    ↓
Resolves bound/available Device
    ↓
Resolves per-account Network Profile
    ↓
Connect VPN/Proxy
    ↓
Health Check / optional region verification
    ↓
Network healthy?
    ├─ No + required -> STOP before app launch
    └─ Yes
         ↓
Restore Workspace
         ↓
Launch Preferred App
         ↓
Run Automation
         ↓
Backup
         ↓
Disconnect account network if configured
         ↓
Release Device
         ↓
Next queued account
