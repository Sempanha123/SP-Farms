SAFETY / PLATFORM CONSTRAINTS:
SP-Farms is for assets the operator owns or is explicitly authorized to manage.

Do NOT implement:
- bulk Facebook account creation
- 5sim/temporary-number Facebook signup automation
- disposable-email Facebook signup automation
- CAPTCHA bypass
- checkpoint/security challenge bypass
- suspension/lock bypass
- fake IMEI/MEID/Android ID/GSF ID/advertising ID/serial/SIM identity
- anti-detect fingerprint rotation
- features intended to hide automation from Facebook
- mass friend requests
- mass likes/comments/story views
- unsolicited bulk messaging
- credential theft/session hijacking
- plaintext secrets

Prefer official Meta APIs where supported.
Use transparent operator-approved device automation only.

ARCHITECTURE RULES:

======================================================================
PHASE 19 — ACCOUNT ONBOARDING WORKSPACE
======================================================================

Create the safe replacement for demo-style account registration.

SUPPORTED SOURCES:
- Connect existing authorized Facebook account through supported official login/OAuth.
- Import authorized metadata.
- Manually add an account record for local management.
- Development/test account mode.
- Attach an already-authorized session only where permitted/supported.

IMPLEMENT:
- Onboarding wizard/panel.
- Required and optional metadata validation.
- Manual phone/email fields.
- Persistent-email guidance: Gmail, Outlook/Hotmail, iCloud, Proton.
- Mask phone/email in general views.
- Preferred app: Facebook, Facebook Lite, Browser.
- Success actions: Open Account, Assign Device, Add Category, Security Center, Pages, Content, Scheduler, Export Metadata.
- Immediately make onboarded account available throughout the app.

DO NOT:
- buy 5sim numbers
- automate Facebook signup
- create disposable emails
- bypass CAPTCHA/checkpoints/security

TEST:
- manual onboarding
- metadata import
- validation
- success routing

DONE WHEN:
- onboarding feels as convenient as "Register Acc" from demo without risky registration automation.
