SAFETY / PLATFORM CONSTRAINTS:
SP-Farms is for assets the operator owns or is explicitly authorized to manage.

Do NOT implement:
- bulk Facebook account creation
- 5sim/temporary-number Facebook signup automation
- disposable-email Facebook signup automation
- CAPTCHA bypass
- checkpoint/security challenge bypass
- suspension/lock bypass
- fake IMEI/MEID/Android ID/GSF ID/advertising ID/serial/SIM identity
- anti-detect fingerprint rotation
- features intended to hide automation from Facebook
- mass friend requests
- mass likes/comments/story views
- unsolicited bulk messaging
- credential theft/session hijacking
- plaintext secrets

Prefer official Meta APIs where supported.
Use transparent operator-approved device automation only.

ARCHITECTURE RULES:
- UI never accesses the database directly.
- Domain layer never imports UI.
- Infrastructure implements interfaces.
- Application services orchestrate use cases.
- No giant `main_window.py`.
- No blocking disk/network/device operations on the UI thread.
- Long-running operations become persistent jobs.
- Secrets never appear in logs or normal exports.
