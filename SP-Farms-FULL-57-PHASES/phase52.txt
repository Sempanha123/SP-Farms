PHASE 52 — FULL AUTOMATION BUILDER
======================================================================

GOAL:
Create one powerful but clean "Automation Builder" where the operator decides exactly which
functions run by selecting accounts/devices/destinations/content and enabling function checkboxes.

Each function must expose its own configuration panel based on function type.

The UI must remain clean through progressive disclosure:
- checkbox enables function
- clicking function row opens its setup panel
- only enabled functions are executed
- saved presets can be reused
